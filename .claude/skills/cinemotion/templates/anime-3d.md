# Anime / Game-Inspired 3D Template

Created and maintained by Aditya (@cixcex).

Use this template for stylized 3D characters and environments.

## Character card

```
name: [name]
proportions: [stylized / chibi / realistic anime]
hair: [color + style]
outfit: [top / bottom / shoes / accessory]
pose_start: [standing/sitting/running]
```

## Scene block

```
Scene N — [name]
- scene_description:
- style_notes: [cel shading, rim light, saturated color]
- camera: [angle + movement]
- environment: [location + objects]
- character_action: [one action]
- lighting: [time of day + key color]
- vfx: [sparkles, speed lines, particles]
- transition:
- ending_state:
- continuity_check:
```

## Quality settings

- Low cost: blocky stylized geometry, one key light, one rim light.
- Balanced: cel-shaded materials, simple particles, soft shadows.
- Maximum quality: full materials, volumetric light, detailed props.

## Rules

- Keep the character card locked.
- Use bold readable silhouettes.
- Add one anime VFX element, not ten.
