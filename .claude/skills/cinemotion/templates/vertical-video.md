# Vertical Short Video Template

Created and maintained by Aditya (@cixcex).

Use this template for 9:16 vertical animation.

## Format constraints

- Aspect: 9:16
- Typical length: 10–30 seconds
- Keep key action in the center safe area.
- Design for sound-off with clear visual beats.

## Scene plan

```
Hook (0–2s): [eye-catching opening]
Setup (2–8s): [character + environment]
Action (8–20s): [main movement]
Turn (20–25s): [change or reveal]
End (25–30s): [final pose or title]
```

## Camera defaults

- POV or third-person close.
- No tiny text; use readable overlays if needed.
- Slow, stable moves; shake only on impact.

## Example

```
Hook: wet neon reflection fills the frame
Setup: character walks into frame, hoodie up
Action: enters convenience store, grabs a drink
Turn: looks out the glass, rain stops
End: small smile, camera settles
```

## Rules

- Cut or dissolve every 2–4 seconds.
- Keep one story beat per scene.
- Preview on a phone-sized canvas.
