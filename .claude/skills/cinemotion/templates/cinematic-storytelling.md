# Cinematic Storytelling Template

Created and maintained by Aditya (@cixcex).

Use this template for connected multi-scene animations.

## One-line premise

> [Who] [does what] [where] [with what result].

## Scene list

```
Scene 1 — [establish]
- duration:
- camera_position:
- camera_movement:
- character_position:
- character_actions:
- environment_details:
- lighting:
- animation_details:
- transition:
- ending_state:
- continuity_check:

Scene 2 — [development]
...

Scene 3 — [resolution]
...
```

## Story beats

1. Establish world and mood.
2. Introduce character and goal.
3. Show one complication or turn.
4. Resolve with a visual change.

## Continuity rules

- Use one character card.
- Use one environment map.
- Reuse the same lighting preset unless time changes.
- Track prop positions between scenes.

## Output

Return the plan as Markdown, then ask whether to generate Three.js, Blender, HTML/CSS/JS, SVG/Canvas, or optional AI video.
