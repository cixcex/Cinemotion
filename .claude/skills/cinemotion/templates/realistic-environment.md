# Realistic Environment Template

Created and maintained by Aditya (@cixcex).

Use this template when the environment is the main subject.

## Environment block

```
Location: [bedroom / street / store / rooftop / restaurant / parking lot]
Time: [dawn / noon / dusk / night]
Weather: [clear / rain / fog / snow]
Spatial structure: [floor, walls, exits, ceiling/sky]
Key objects: [3–5 required props]
Background detail: [posters, cables, skyline, shelves]
Atmosphere: [fog, rain, dust, steam, neon haze]
Light sources: [type, color, intensity]
Camera placement: [position and target]
Environmental animation: [one subtle motion]
```

## Example

```
Location: convenience store
Time: night
Weather: light rain
Spatial structure: glass front, aisles, checkout, cooler doors
Key objects: shelf rows, register, drink cooler, umbrella stand
Background detail: menu board, poster, exit sign
Atmosphere: cold fluorescent interior + wet pavement reflections
Light sources: overhead fluorescent (cool white), neon sign (cyan)
Camera placement: outside glass, eye level, slow dolly in
Environmental animation: rain ripples and door chime
```

## Rules

- One dominant light source.
- One secondary color accent.
- At least one moving element.
- Keep camera placement consistent with the action.
