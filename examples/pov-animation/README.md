# POV Animation Example

Created and maintained by Aditya (@cixcex).

A lightweight first-person POV preview generated by CINEMOTION. It runs in any modern browser and uses no dependencies.

## Files

- `index.html` — vertical 9:16 canvas page.
- `main.js` — scene animation.
- `scene-plan.md` — structured scene plan.

## Run

Open `index.html` in a browser, or serve the folder with any static server.

## Limits

This is a lightweight 2D preview example, not a full 3D render. It demonstrates the CINEMOTION scene-plan-to-code workflow.
