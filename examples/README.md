# Examples

Created and maintained by Aditya (@cixcex).

Each example is a small, runnable browser preview plus its CINEMOTION scene plan.

| Example | Engine | Shows |
|---|---|---|
| `pov-animation/` | Canvas | First-person night walk with continuity state |
| `anime-environment/` | Canvas | Stylized environment, locked character card |
| `cinematic-night-scene/` | Canvas | Neon lighting, rain, reflections |
| `vertical-short-video/` | Canvas | 9:16 beat structure for short video |

Run any example by opening `index.html` in a browser, or:

```bash
cd examples/pov-animation
python3 -m http.server 8000
```

These are lightweight previews, not final rendered videos. They demonstrate the planning-to-code workflow only.
