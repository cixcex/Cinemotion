# Cinematic Night Scene Example

Created and maintained by Aditya (@cixcex).

A neon-lit night street preview generated by CINEMOTION. It runs in any modern browser and uses no dependencies.

## Files

- `index.html` — vertical canvas page.
- `main.js` — night lighting and rain animation.
- `scene-plan.md` — structured scene plan.

## Run

Open `index.html` in a browser, or serve the folder with a static server.

## Limits

This is a lightweight 2D example, not a Three.js or Blender render.
