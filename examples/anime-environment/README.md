# Anime Environment Example

Created and maintained by Aditya (@cixcex).

A stylized anime-inspired street preview generated by CINEMOTION. It runs in any modern browser and uses no dependencies.

## Files

- `index.html` — vertical canvas page.
- `main.js` — stylized environment animation.
- `scene-plan.md` — structured scene plan.

## Run

Open `index.html` in a browser or serve the folder with a static server.

## Limits

This is a lightweight 2D example, not a full 3D anime render.
